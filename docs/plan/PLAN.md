# Bitcoin Time Series Analysis ML Project (High Level)

## Description: 
- Planning document for the btc time series analysis model.

## Steps: 
- Step 1: Determine what type of time series data will be easier to model. 
    - Minute, hour, day, week, month, and yearly. 
- Step 2: Examine 3 data sources for price data collection. 
- Step 3: Select data source from group of 3. 
- Step 4: Explore and visualize the time series data to identify noide, trend, 
seasonal, and clycical components. 
- Step 5: Train on selected model from SARIMA, ARIMA, or exponential smoothing
based on prior analysis. 
- Step 6: Validate model on historical back testing to determine loss.
- Step 7: Repeat steps 5 and 6 until loss function target is met. 
- Step 8: Package and deploy model to cloud environment. 
- Step 9: Execute a live run of the model to determine real world accuracy. 
- Step 10: Create detailed READ.me and publish to github, discord channels, and 
LinkedIn for project showcase. 

## Output: 
- A time series model trained to forecast Bitcoin price data.
